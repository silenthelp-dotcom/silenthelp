Founder headshots go here.

Save each as:
  sree.jpg      — Sree Saran Lakkaraju
  abhinav.jpg   — Abhinav Allani
  nehanth.jpg   — Nehanth Arvapalli

Square images work best (they're shown in a circle). ~400x400px is plenty.
Once a file is here, set its `photo` field:
  - about page:   templates/about.html  → TEAM[].photo = "/static/img/team/<slug>.jpg"
  - landing page: templates/landing.html → window.SH_TEAM[].photo = same

Until then, each card shows a monogram avatar (the person's initials).
